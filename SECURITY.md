# Security

This repository contains only text files: the translations of BlockFactory and, later, its wiki. It holds no code
that runs on your computer or on a server.

## Reporting a problem

If you find something that should not be public, for example personal data, a password or a key in a file or in the
history, or a text that could harm players, please **do not open a public issue**. Report it privately instead:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability** and describe what you found and where.

You will get an answer as soon as possible. Please give the maintainer a chance to fix it before you tell others.

For mistakes in a translation or in an English text, use the normal issue forms instead.
